Чтобы скачать репозиторий команды Platform, открой его в Bitbucket, скопируй SSH-адрес через Clone и выполни git clone с этим адресом. Создай ветку от main для своей задачи. Перед отправкой pull request запусти тесты, укажи ссылку на задачу из Jira и опиши, как проверял изменения. Выбери main целевой веткой и дождись результата CI. Если сборка упала, открой лог упавшего шага и приложи его к вопросу наставнику.
