# Guardrails AI-сервиса

Политика реализует границы из [SDD](rag-sdd.md). Общая точка генерации используется CLI, REST и gRPC. Контракты статусов сохранены.

| Граница | Проверка | Результат нарушения |
|---|---|---|
| Вход | Длина, тип, управляющие символы; доверенные роль/команда задаются сервером. | Ошибка входных данных. Текст вопроса не меняет ACL. |
| Поиск | ACL и опубликованная версия до отбора контекста; повторный ACL-фильтр перед генерацией. | Скрытые и отсутствующие документы неразличимы для пользователя. |
| Актуальность и конфликты | Проверка срока и размеченных `rule_key`/`rule_value` до LLM. | `needs_review` либо `conflict`, ссылки и эскалация, без провайдера. |
| Внедрение инструкций | Консервативный детектор явного переопределения правил в вопросе, тексте, заголовке и значении правила; NFKC и обработка невидимых символов. | `insufficient_evidence`, эскалация, без цитирования атаки и без LLM, в том числе офлайн. |
| Ответ провайдера | Завершение `stop`, строгий JSON без повторяющихся ключей, известные цитаты, ограничения 32 шага / 2000 символов на шаг / 16000 символов JSON, отсутствие tool/function calls. | Ответ целиком отклоняется; частичный ответ и автоматический офлайн-переход не выдаются. |
| Текст модели | Явные утверждения о выполненной заявке/выданных правах, выдуманные номера BUD-ACCESS, активная разметка, ссылки вне процитированных источников, управляющие символы. | `GuardrailError`; REST — 503, gRPC — UNAVAILABLE, общий код `temporarily_unavailable`. |
| Действия | `ask` только читает. `preview_jira_access` вычисляется кодом по роли, команде и источнику; модель не задаёт действие. | Создание заявки возможно только отдельным обработчиком явного подтверждения с повторной проверкой полномочий. |

Код отклонения ответа записывается в серверный лог без вопроса, ответа, ключей или содержимого документов. Клиент получает общий код ошибки. Текст ответа и источников следует отображать как текст, а ссылки — брать из структурированных полей.

Проверка наличия цитаты не доказывает, что источник подтверждает утверждение. Регулярные выражения ловят перечисленные классы атак и явные утверждения о действиях, но не гарантируют обнаружения произвольных перефразировок или всех prompt injections. Возможны консервативные отказы при цитировании самих атак. Семантические галлюцинации, полнота ответа, смысловые конфликты без разметки и происхождение demo проверяются по размеченным [evals](../rag/evals/README.md). Граница выполнения действий обеспечивается архитектурой и полномочиями обработчика, независимо от детектора текста.

Обнаружение подозрительного разрешённого фрагмента останавливает весь ответ: тихое удаление одной стороны могло бы скрыть конфликт. Чужой фрагмент отбрасывается по ACL раньше этой проверки. `/v1/search` остаётся поиском разрешённых документов; детектор применяется при подготовке ответа, а не изменяет содержимое базы знаний.
