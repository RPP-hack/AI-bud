# Проверка выпуска

Проверено локально 16 ноября 2026 года в ветке `backend-branch`.

## Код

- Go: форматирование, vet, тесты с `-race` и интеграции с отдельными временными PostgreSQL-базами прошли.
- Python: 82 теста прошли, включая REST/gRPC, ACL, сохранение границ источников и классификацию ошибок.
- Frontend: 30 тестов и production-сборка прошли.

- Исполняемые строки всего приложения: 2695/2914, 92.48%. [Методика](COVERAGE.md), [отчёт](coverage/SUMMARY.md).

## Полный Docker-стек

Проверены gateway, Go API, Python gRPC, PostgreSQL/pgvector, локальная BAAI/bge-m3 и `nvidia/nemotron-3.5-lightning:free` через OpenRouter. Переданы только согласованные синтетические вопросы и их тестовая история.

1. «Привет» возвращает представление без поиска и внешней модели.
2. «Не открывается Jira, ошибка 403. Какой доступ мне нужен?» получает ответ по jira-access с предложением заявки. Финальный прогон: 15.57 секунды. В предыдущем прогоне первый запрос занимал 32.58 секунды, поэтому мгновенный ответ на CPU не гарантируется.
3. «А к какому именно проекту? Я забыл его название.» получает «Проект BUD» со ссылкой на текущий источник. Финальный прогон: 0.82 секунды. Повторно используется вектор предыдущего содержательного вопроса, а уточнение и история передаются модели.
4. Повтор с тем же idempotency key возвращает прежний результат. GET восстанавливает сохранённые ответы и источники.
5. Другой профиль не видит диалог и заявку владельца. Стажёр Search и наставник не могут отправить заявку BUD.
6. Стажёр Platform создаёт предложение, подтверждает его, получает сохранённый номер mock-заявки и статус pending. Обновление достигает granted, следующий шаг становится done.

Проверка выполнена через HTTP полного приложения и реальные gRPC/LLM-вызовы. GUI дополнительно покрыт frontend-тестами; для PDF получен снимок реального интерфейса в отдельном браузерном профиле.

## Ограничения

Корпоративные интеграции и авторизация имитируются. Корпус учебный. Тематический отбор использует небольшой набор правил, универсальный reranker отсутствует. Успешный прогон не гарантирует качество произвольного вопроса, скорость следующего холодного запуска или доступность бесплатного провайдера. Права доступа к предоставленной папке с видео, содержимое видео и отправка на платформу не проверены.
